# Registration Form CLI

A simple Python command-line registration form that allows users to enter their personal and employee information.

## Features

* Enter first name and last name
* Enter address information
* Enter age and years of experience
* Enter job position and salary
* Generate an employee card
* Extract department, year, and initials from an employee code

## How to Run

1. Make sure Python is installed.
2. Download or clone this project.
3. Open a terminal in the project folder.
4. Run the program:

```bash
python registration_form.py
```

## Example

```text
=== Registration Form ===
Enter your first name: Alice
Enter your last name: Smith
Enter your age: 22

Alice Smith is 22 years old
```
